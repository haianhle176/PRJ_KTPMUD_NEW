# P1 Integration Profiles

Ba profile khong chua secret, dung de kiem thu P1-10 voi HiveMQ Cloud va Azure SQL.

- `environment-sensor`: temperature va humidity sensors.
- `garden-pump`: boolean pump actuator.
- `smart-room`: light sensor va light actuator.

Chay DeviceApp voi `DeviceApp__DataDirectory` tro toi thu muc nay va `--profile` bang ten thu muc con.
